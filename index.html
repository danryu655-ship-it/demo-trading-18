06 · Aturan Strategi (LONG + SHORT)

Candle 1 jam · EMA9 cross EMA21 + filter EMA50 + Bias Momentum + RSI14 · SL 1,5× ATR(14) · TP 2R · Risiko 0,4% per trade · Maks 3 posisi · Batas rugi harian $20 (kill switch). Fee simulasi 0,06% + slippage 0,02% per sisi. SHORT di demo ini hanya simulasi — di trading real, short TIDAK bisa di Spot, harus lewat Futures/margin dengan risiko likuidasi.

Backtest 7 hari (17–24 Nov 2026), jujur: KALAH — long-only 20 trade, profit factor 0,61, saldo $976,85 (−2,32%); long+short 30 trade, profit factor 0,77, saldo $980,79 (−1,92%). Kriteria lulus: profit factor > 1 setelah 30 trade. Strategi ini belum lulus — jangan pakai uang asli.

07 · Cara Menutup Posisi dari PC

Versi GitHub Pages ini tidak bisa menutup posisi secara instan — tidak ada server di belakangnya. Tombol “Tutup Sekarang” di kartu posisi membuka konfirmasi berisi harga live + estimasi P/L dan perintah yang bisa disalin. Penutupan terjadi setelah kamu menjalankan perintah itu di PC (di folder hasil git clone):

node close-request.cjs <KOIN>   # contoh: node close-request.cjs SOMI
node engine.cjs                  # mesin menutup di harga live, alasan MANUAL-CLOSE

Untuk tutup semua posisi: node close-request.cjs ALL lalu node engine.cjs. Atau bilang tutup <KOIN> di chat ke Rias.
